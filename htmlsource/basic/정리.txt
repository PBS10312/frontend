form : 다른 form 을 자식요소로 사용할 수 없음 (form 안에 form 못옴)
        속성
        1) * action : 경로 (전송한 정보를 처리할 웹페이지 URL)
             ㄴ "" : 자기자신 
        2) * method : GER , POST
        3) autocomplete : 자동완성 사용 여부 (default -on)
        4) name : 고유한 양식의 이름
        5) novalidate : 서버로 데이터 전송 시 유효성 검사하지 않음
           ㄴ 속성을 지정 안하면 
              ㄴ email : 입력값이 존재할 때 간단하게 이메일 형식이 맞는지 확인
              ㄴ required : 필수입력

       - 경로 해석 -
        http://192.168.55.2:5500/basic/from1.html?fruits=on&fruits1=on

        http://192.168.55.2:5500/ => 임의로 서버를 만들었기 때문에 포트서버
        ex) http://ip주소:포트번호 인것

        
        /basic/from1.html? => 위에 설명한 "" 기준은 , ? 를 기준으로 삼음
        ex) http://ip주소:포트번호/basic/from1.html 인것

        fruits=on&fruits1=on
        서버경로?키=값&키=값

        get 방식 : 데이터 전송 시 아래와 같은 형태로 따라감

        ?text1=123&name=123&fruits=포도&fruits1=바나나
        
        키 : name
        값 : text(입력값) , checkbox,radio(value)


        input type
        1) text : 문자 한 행 입력용
        2) radio : 여러 개 중에서 하나 선택 용으로 사용
        3) checkbox : 여러 개 중에서 여러 개 선택 용으로 사용
        4) button : 모양만 버튼 모양으로 나옴
        5) reset : form 안의 입력 내용 초기화
        6) submit : action 이 지정한 곳으로 폼 내용 전송

 속성
        
        1) value : radio , checkbox , option , submit , reset , button 필수사용 , 나머지는 선택
        2) readonly : 수정불가
        3) required : 필수입력
        4) autofocus : 입력 수신대기
        5) disabled : 이용 불가 (막는거)
        6) size,maxlength,min,max : 입력창 크기 , 입력시 갯수제한 , 
        7) multiple : file 여러개 설정
        8) pattern : regex를 이용한 입력형식 지정
        9) placeholder : 사용자에게 예시보여주기? (form1 확인)
        10) setp : 단위 설정 => 1개씩 올라가는거 뭐 3개씩 5개씩 이런식으로?
